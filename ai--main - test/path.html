从零到第一个项目

这条路线是社团三年里反复打磨出来的：不追求把书读完，而是每一阶段都留下一个能跑的东西。 四周一次自检，卡住了直接找导师，不用一个人硬扛。

四个阶段

Self-paced · Mentor supported
01 Python 与数学基础 4—6 周

目标：能独立写脚本处理数据，看懂论文里的公式符号，不再被环境配置卡住。

  • Python 语法、数据结构与函数，重点是写得出、跑得通。
  • NumPy 与向量化思维：把 for 循环换成数组运算。
  • 线性代数、概率与微积分的最小必要集，够用就好。
  • Git 与虚拟环境：把自己的代码管起来，也敢提交 PR。
Python 入门资料 数学速查笔记
02 机器学习核心概念 6 周

目标：知道一个模型为什么有效、什么时候会失效，并能完成一次完整的训练与评估。

  • 线性回归、逻辑回归与损失函数：从最小二乘到梯度下降。
  • 树模型与评估指标：准确率之外，还要看召回与 AUC。
  • 过拟合、正则化与数据泄漏：新手最常踩的三个坑。
  • 一次完整的校内数据小赛，从清洗到提交。
CS231n 精读笔记
03 深度学习与 Transformer 8 周

目标：能手写一次反向传播，读懂 Transformer，并微调一个属于自己的小模型。

  • 神经网络与反向传播：先手推一遍，再用 PyTorch 复现。
  • 训练循环、学习率与显存：把模型真正训起来。
  • Attention 与 Transformer：从 Q / K / V 到多头注意力。
  • 微调与评测：让一个小模型在你关心的任务上变好。
Transformer 演进地图 RAG 实战教程
04 选择方向，开始做项目 持续

目标：加入一个在研项目，或者带着自己的想法组队，把它做到能被别人使用。

  • 六个方向任选：LLM & Agents、Computer Vision、Embodied AI、AI × Design、AI Ethics、Creative ML。
  • 进入三人小队，跟着项目组做两周一次的进度同步。
  • 在 Demo Day 上公开演示，接受真实用户的评价。

每周的节奏

Weekly Rhythm
  • 周三：资料库更新，路线清单同步最新推荐。
  • 周六下午：Paper Club 共读，从摘要读到实验部分。

  • 导师 1v1：入社前三个月，每月一次 30 分钟的路线校正。
  • 卡住超过两天，直接在群里问，不要一个人耗。
