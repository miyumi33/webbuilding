# NEXUS AI · 大学人工智能协会

深色 / 浅色双主题的社团官网，由首页与四个子页面组成，面向大学 AI 社团场景。整个站点为纯前端静态页面，主题切换、粒子背景与表单摘要使用原生 JavaScript；没有后端，申请与建议通过本地摘要 + 邮件草稿完成。

## 开屏动画 · Boot Sequence

首页加载时会先播放约 2.2 秒的开屏：网格与星点铺底 → NEXUS 星标描边成形 → 字母逐字升起 → 启动日志逐行打印、进度条跑到 100 → 整屏收束成一道 1px 光带并溶解，露出已经排好的 Hero。

- **剧本**：`intro.js` 管时序（日志逐行出现、0—100 计数、2.14s 触发退场），`intro.css` 管画面（网格、星点、扫描线、四角 HUD、轨道环、溶解成线）
- **配色**：全部取 `styles.css` 的主题变量，深色是蓝黑 + 雾蓝，浅色自动变成米白纸感 + 棕金，不需要另写一套皮肤
- **退场**：`.is-exiting` 用 `clip-path: inset()` 把整屏压成一条光带，同时解除 Hero 的入场闸门，开屏溶解与页面落位是同一段时间
- **跳过**：点击、滚轮、滑动、任意按键、右下角「跳过 SKIP」都会立即结束；`prefers-reduced-motion` 下不播动画，直接淡出
- **只播一次**：同一会话内只播一次（`sessionStorage`），手动刷新会重播；强制重播 `index.html?intro=1`，关闭 `index.html?intro=0`
- **兜底**：`intro.js` 若没加载成功，页面顶部内联脚本会在 7 秒后撤掉遮罩，Hero 不会被永久藏住
- **只在首页**：子页面不播（从首页点进去再被打断会很难受）。要在子页面启用，把 `intro.css`、遮罩节点、`intro.js` 复制过去，并带上 `<head>` 里那段 gate 脚本

## 页面跳转与表单

- 首页所有操作型按钮均已改为真实链接（`<a>`），不再是占位 `<button>`；导航锚点仍留在首页内

## 局域网预览

- 双击 `serve-lan.bat`：自动寻找 Python，启动只读站点服务（默认 8000 端口），并打印本机与局域网地址
- `serve-web.py` 只发布网站文件（`.html/.css/.js/.svg/.png`），README、预览图与服务脚本一律 404，目录浏览已关闭
- 如需让手机访问，Windows 防火墙需放行该端口（初次可用管理员 PowerShell 执行 `netsh advfirewall firewall add rule name="NEXUS AI LAN 8000" dir=in action=allow protocol=TCP localport=8000`）

## 双主题设计

- **深色模式**：`#07090e` 蓝黑底，雾蓝重点色，冷调暗色界面（保留原版设计）
- **浅色模式**：`#f3ede2` 米白底，棕色与黑色文字、边框、图标和强调背景，整套界面不再使用蓝色

## 点线粒子背景

- 复用本地 `particle-net.js` 引擎，固定为全站背景层：99 点基准、按视口密度自适应、两点连线、鼠标推开粒子
- **浅色模式使用纯黑粒子，深色模式使用纯白粒子**；画布整体透明度降低，避免干扰正文阅读
- 主题切换时粒子颜色实时更新；支持 `prefers-reduced-motion`，页面隐藏时自动暂停
- 主内容与卡片位于粒子层之上，保证可读性；浅色 / 深色的小面板保持独立层次

## 手机 / 电脑双端适配

同一套 HTML / CSS 在手机、平板与桌面共用，不需要单独的移动端文件：

- **断点**：1240 / 1100 / 1024 / 860 / 700 / 430 / 380 / 360 / 320，覆盖折叠屏（280px）到 2560px 桌面，任意宽度下无横向滚动
- **移动端字号**：手机端正文字号 13—14px，说明性标签不低于 9.5px；装饰用 HUD 标注保留小字号但同步上调，避免手机上看不清
- **触控目标**：导航开关、主题按钮为 44 × 44，菜单项高 48px，页脚链接与次要按钮高度不小于 38—44px
- **折叠菜单**：`<details>` 原生菜单在点击导航项、点击菜单外区域、按 Esc、或视口切回桌面时自动收起（`nav.js`）
- **安全区**：`viewport-fit=cover` 配合 `env(safe-area-inset-*)`，刘海屏与底部手势条不遮挡内容
- **横屏与折叠屏**：横屏手机收紧标题与分区间距，菜单可滚动；280—360px 下重排统计、列表与轨道尺寸
- **指针差异**：悬停位移只在有鼠标的设备生效，触屏使用按下反馈，避免 hover 状态残留
- **锚点定位**：`scroll-padding-top` 随安全区变化，跳转后标题不会被吸顶导航遮挡

### 典型修改案例：局域网发布从「共享整个目录」收敛为「只发布站点资源」

**AI 原始输出**

最初把需求理解为「整个项目目录对外可访问」，直接用 Python 自带的静态服务器把整个项目目录当作根目录：

```powershell
python -m http.server 8000 --bind 0.0.0.0 --directory "C:\...\ai--main - test"
```

根路径虽然会返回 `index.html`，但 `README.md`、`preview-*.png`、服务脚本以及任意子目录同样可访问，目录列表默认开启。AI 在说明里也写了「暴露的内容是整个文件夹的只读列表」。

**人工调整**

> 发布范围应限定为站点自身的页面与资源：README、预览图、部署脚本等与站点无关的文件不纳入对外访问。

**调整方案**

改为项目内的 `serve-web.py`，只发布站点文件：

```python
PUBLIC_EXTENSIONS = {".html", ".css", ".js", ".svg", ".png", ".jpg", ".jpeg", ".webp", ".ico"}
DENY_NAMES = {"readme.md", "serve-web.py", "serve-lan.bat"}
DENY_PREFIXES = ("preview-",)
```

- 根路径固定返回 `index.html`，其余请求按扩展名白名单放行，文件不存在则 404
- `list_directory` 直接返回 404，关闭目录浏览
- 拒绝含 `/`、`\` 或以 `.` 开头的路径，避免越权访问
- 逐条请求验证：站点页面与资源 200；`README.md`、`preview-dark.png`、`serve-web.py`、`serve-lan.bat`、`/page.css/` 均为 404

**修改原因**

1. 最小暴露面：README、预览图、部署脚本与站点无关，不应出现在局域网
2. 避免信息泄漏：目录列表会暴露项目结构与未完成内容
3. 语义正确：需求边界是「发布网站」，而非「共享开发目录」
